## What I Learned
**Topic : Understanding my project's history**
- *The history is a chain*
- Every commit point to its parent
- Head point towards main(HEAD -> main -> commit)
**Branch vs Commit**
- main is not a commit itself, it is a reference pointing to commit(The reason git is lightweight)
